# Gerenciador de Documentos — Congregação Parque Scaffid

Aplicação web para gerar os documentos mensais da congregação a partir dos dados do mês, mantendo a identidade visual padronizada.

Contexto completo do projeto (estado, decisões, roteiro): [`PROJETO.md`](./PROJETO.md).

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Publicação

Cada push é publicado automaticamente no GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`).
